# SIGIL-Digital-Signature-Application
SIGIL është një aplikacion për nënshkrime dixhitale, i zhvilluar në Python në kuadër të lëndës së Kriptografisë. Implementon algoritmin RSA dhe funksionin SHA-256 për gjenerimin e nënshkrimeve, sigurimin e integritetit dhe verifikimin e autenticitetit të dokumenteve dixhitale.
